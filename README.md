# ☁️ Backend & Cloud Auditor Skill

A comprehensive, enterprise-grade AI skill that transforms any AI agent (Gemini, Claude, GPT) into an **Ethical Hacker (Red Team), Cloud Architect, and Security Auditor**.

## 🎯 What This Skill Does

When loaded by an AI agent, it forces the agent to perform a **19-phase exhaustive analysis** of any backend/API/cloud infrastructure, covering:

| Phase | Focus |
|-------|-------|
| 1 | Architecture & Topology |
| 2 | Business Logic & Integrity |
| 3 | API & Omnichannel Gateway |
| 4 | Real-time & Async Systems |
| 5 | Database & Data Architecture |
| 6 | Distributed Caching & Edge |
| 7 | Concurrency & Load Scalability |
| 8 | Auth & Identity Management |
| 9 | **Advanced Security Defenses** (OWASP API + mandatory web search) |
| 10 | Resilience & Fault Tolerance |
| 11 | Observability & Auditability |
| 12 | Infrastructure, Cloud & CI/CD |
| 13 | Compliance & Disaster Recovery |
| 14 | Zero Trust & Service Mesh |
| 15 | Supply Chain & GitOps |
| 16 | Advanced Threats & Forensics |
| 17 | Final Delivery + **Fresh-Eyes Re-Analysis** |
| 18 | Structured Remediation (with Hacker Mindset R6) |
| 19 | **Pre-Deployment Sentry Validation** |

## 🛡️ Anti-Laziness Features

- **153 minimum code citations** required across all phases
- **Mandatory web search** in multiple phases for current-year CVEs
- **Fresh-Eyes re-analysis** with 4-layer reminder system
- **Hacker Mindset R6** post-fix verification
- **Cross-Reference Matrix** — proves every file was examined

## 🔧 Supported Environments

Localhost, VPS, Docker, Kubernetes, Serverless, AWS, GCP, Azure — with frameworks: Node.js/Express, Python/Django/FastAPI, Go, Java/Spring, PHP/Laravel, Ruby/Rails, .NET/ASP.NET

## 📦 How to Use

1. Load this skill folder into your AI agent's skill/plugin system
2. Tell the agent: "Run the backend auditor skill on my project at [path]"
3. The agent will execute all 19 phases automatically with stop points
